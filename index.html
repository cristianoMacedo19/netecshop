Laboratório de Automação de Testes com Selenium Teste de Software · IFMA Campus Timon

Bem-vindo

Este ambiente tem duas partes: uma aplicação web fictícia que servirá de alvo para os seus testes e um roteiro guiado que conduz você, passo a passo, da gravação no Selenium IDE até uma suíte automatizada em Python com pytest.

1. Roteiro guiado → Comece por aqui. 15 etapas que aparecem uma de cada vez, conforme você as conclui. O progresso fica salvo no seu navegador. 2. NetecShop (aplicação-alvo) A loja fictícia que será testada. Abra em outra aba e deixe aberta durante todo o laboratório.

Antes de começar

  • Use o Firefox. A extensão do Selenium IDE não está mais disponível para o Chrome.
  • Tenha Python 3.12+ instalado.
  • Reserve cerca de 3 horas para percorrer todas as etapas com calma.

O que você vai praticar

  • Gravação e exportação de testes com o Selenium IDE
  • Selenium WebDriver com Python e pytest
  • Esperas explícitas com WebDriverWait e condições esperadas
  • Seletores estáveis, coleções de elementos e casos negativos
  • Diálogos nativos do navegador, formulários e iframes
  • Page Object Model e execução em modo headless
Aviso. A NetecShop é uma aplicação de treinamento. Nenhum dado digitado é enviado a servidores: tudo fica na memória do navegador e é apagado ao recarregar a página. Nunca use dados pessoais reais aqui.
